# 闪卡：宠物闪卡原型

手机网页原型：上传宠物照片，在浏览器中抠出主体，将宠物层放在柔化的照片背景前方。划过卡片或允许手机倾斜，可以看到视差和四种动态箔面。

## 本地运行

```bash
npm ci --ignore-scripts
npm run dev
```

首次抠图会从 Hugging Face 下载 `onnx-community/ormbg-ONNX` 的量化模型，在设备上运行。需要可以连接 Hugging Face 的网络和足够的设备内存。无法下载或未识别出主体时，卡片仍可显示普通箔面效果。透明背景 PNG / WebP 可以直接形成前景层，不需要模型。

“保存到此设备”将最近一张卡片保存在浏览器 IndexedDB 中；刷新后会恢复。清除浏览器站点数据会删除作品。“下载静态图片”生成 PNG，动态倾斜与箔面不会保留在 PNG 中。照片不会通过本项目的服务器上传；模型资源会从 Hugging Face 获取。

这仍是原型：前景采用自动去背景，背景由原照片柔化而成，没有对宠物原位置做内容填充；复杂毛发、多人或多宠物场景可能需要改进。样例卡也要点“用样例试立体效果”触发首次处理。

卡片反光基于 MIT 许可的 `@kongyo2/cards-css`；抠图运行库和模型为 Apache-2.0。上线前仍需在真实 iPhone、Android 上验证下载速度、内存和传感器授权。
